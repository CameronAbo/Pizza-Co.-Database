# Pizza Co. Database
The environment being simulated for the Database being created is based on a State-Wide Pizza chain with multiple store fronts throughout the state of California. The simulated business will have an online ordering system for deliveries and takeout orders and must be able to keep track of customer accounts along with related data including purchase history, primary store locations, and saved payment methods.
